# Game Library Service

A backend service for managing users, games, and user game libraries.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Psycopg
- Poetry

## Current Features

- User CRUD APIs
- PostgreSQL relational schema
- Many-to-many user/game relationship
- Connection pooling
- Transaction handling

## Planned

- Repository/service architecture
